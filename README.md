# Sannidhi Physiotherapy & Rehabilitation

Website for Sannidhi Physiotherapy & Rehabilitation clinic, built with Next.js.

## Features

- Landing page with hero, about, and doctor profiles
- Clinic contact information
- Smooth animations with Framer Motion

## Tech stack

- [Next.js](https://nextjs.org/) 16 (App Router)
- React 19
- TypeScript
- Framer Motion
- Lucide / React Icons

## Project structure

```
src/app/
  layout.tsx        Root layout
  page.tsx           Main landing page
  globals.css        Global styles
public/
  images/            Site images (hero, about, doctor photos, logo)
```

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Build

```bash
npm run build
npm run start
```

## Linting

```bash
npm run lint
```
